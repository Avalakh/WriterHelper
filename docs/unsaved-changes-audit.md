# Проверка несохранённых изменений

Проверено 14 октября 2026 года в версии 0.1.5. Все проверки выполнены в отдельных тестовых базах и отдельных профилях Edge. Рабочий проект автора не использовался для записи.

| Разделы | Что проверено | Результат |
| --- | --- | --- |
| Стиль, описание мира, сюжет, планы глав, сцены, рукописи | Фокус без ввода, реальная правка, полный откат, «Не сохранять», «Оставить черновик», восстановление | Пройдено |
| Персонажи, особенности по книгам, источники, правила мира | Те же сценарии, сохранение других материалов и их черновиков | Пройдено |
| Предпросмотр | Фокус полей, масштаб, прокрутка, размер окна, правки оформления и восстановление | Пройдено |
| Проект, книга, лор, список персонажей, поглавный план, список сцен | Просмотр и переходы без ложного предупреждения | Пройдено |
| Дополнительные свойства JSON | Эквивалентный формат и порядок ключей, незавершённый ввод, отмена и восстановление | Пройдено |
| Настройки ИИ | Правки модели, отмена, черновик, восстановление и сохранение подключения | Пройдено |
| Библиотека промптов | Изменения текста и метаданных, откат пустых условий, отмена, черновик и сохранение | Пройдено |
| Конструктор генерации | Выбор стрелки без правки, изменение схемы, подготовленный внешний источник, отмена, восстановление и сохранение | Пройдено |
| Кандидат ИИ | Отмена, черновик и восстановление без записи в исходную рукопись | Пройдено |
| Задача генерации | Черновик, восстановление и отмена только текущего материала | Пройдено |
| Импорт JSON, импорт каталога, библиотека | Просмотр не создаёт несохранённых изменений фоновой книги | Пройдено |

Локально также проверены временные параметры выгрузки книги: изменение автора/формата выгрузки не изменяет книгу и её черновики. Эта функция присутствует в авторской рабочей версии.

В каждом сценарии отмены и черновика проверялся неизменный контрольный черновик другого материала. Дополнительно проверен другой материал с похожим префиксом ID: отмена свойства JSON его не удаляет. В сценариях явного сохранения настройки, промпта и схемы проверялось изменение только их собственных записей.

## Исправлено по результатам проверки

- Защита перехода добавлена в настройки ИИ, промпты и конструктор.
- Пустое необязательное поле после полного отката сравнивается с исходным незаполненным состоянием. Неизвестные авторские поля остаются значимыми.
- После полного отката удаляется только автосохранённый в текущем сеансе отменённый черновик. Намеренно оставленные черновики сохраняются.
- При работе с JSON ожидаются записи только текущего материала; отмена проверяет тип записи и не удаляет чужие материалы с похожими ID.
- Ошибка предыдущего редактора очищается при открытии другого материала.
- После перехода к служебному разделу фоновая книга не вызывает повторное предупреждение; её оставленные правки сохраняются.

Ключ доступа подключения не входит в локальный черновик: при восстановлении параметров его нужно ввести заново. Для сохранения ключа используется «Сохранить подключение».
