# Железный разум — рабочие исходники книги

Мы пишем «Железный разум» вместе с читателями. Здесь хранится действующая авторская версия: три книги, планы, сцены, персонажи, правила мира и рукописи. Сейчас в проекте 94 главы, 194 сцены и 36 глав с написанной прозой; в книге 3 пока публикуются планы и сцены без выдуманной прозы.

Это поддерживаемые исходники проекта: автор обновляет их из WriterHelper, а изменения сохраняются в истории Git. WriterHelper остаётся самостоятельной программой для любых книг.

## Как открыть

**Через JSON:** скачайте [архив материалов](https://github.com/Avalakh/WriterHelper/releases/latest) либо клонируйте репозиторий. В WriterHelper откройте «Импорт JSON» и выберите одновременно project.json, book-1.json, book-2.json и book-3.json. Проверьте пакет, затем загрузите его. Можно также выбрать этот каталог через «Загрузить из каталога».

**С рабочей базой и историей:** установите WriterHelper в отдельную новую папку, завершите его через «Выход» в трее и скопируйте содержимое каталога data отсюда в его папку data. Запустите WriterHelper и выберите книгу. Не заменяйте этим каталогом свою существующую рабочую базу: для неё используйте JSON-импорт с проверкой конфликтов.

- project.json и book-N.json — читаемые материалы для сравнения правок в Git.
- data/writer.sqlite — рабочие материалы, авторские промпты, схема и история сохранённых редакций.
- data/sources — исходные снимки, на которые ссылается база.

В опубликованной рабочей базе отсутствуют подключения ИИ, ключи, кандидаты генерации, технические отчёты импорта и профиль браузера. Настройте свою модель самостоятельно. Несохранённые браузерные черновики остаются у автора локально; для публикации правку сначала нужно сохранить в приложении.

## Как участвовать

Обсуждайте книгу и предлагайте идеи в [Issues](https://github.com/Avalakh/WriterHelper/issues). Для своей версии создайте fork. Основную версию изменяет автор; изменения из GitHub в авторский рабочий проект не загружаются.

## Обновление автором

После сохранения материалов в WriterHelper, из корня репозитория:

```powershell
npm run book:publish -- "D:\Work\projects\WriterHelper\data" books/iron-mind
git diff -- books/iron-mind
git add books/iron-mind
git commit -m "Обновить Железный разум"
git push
```

Первый аргумент — ваша рабочая папка data. Команда только выгружает её в репозиторий и не изменяет источник. Просмотрите изменения перед коммитом. Автоматической обратной загрузки, публикации по таймеру или изменения авторского проекта из чужих форков нет.
