# WriterHelper

WriterHelper — локальное рабочее место автора для написания книг. В одном проекте можно вести несколько книг, планы глав и сцен, персонажей, мир, стиль и рукописи. Есть помощь ИИ, локальные черновики, история правок и предпросмотр страниц. В репозитории также ведём книгу **«Железный разум» вместе с читателями** — её [рабочие исходники и база](books/iron-mind) доступны для знакомства с программой, чтения и создания форков.

## Быстрый запуск в Windows

1. Скачайте **WriterHelper-Windows-x64.zip** из [Releases](https://github.com/Avalakh/WriterHelper/releases/latest).
2. Распакуйте весь архив в отдельную папку и запустите **WriterHelper.exe**. Терминал и отдельная установка Node.js не нужны.
3. При первом запуске **«Железный разум» уже загружен**: открывается первая написанная глава, доступны все три книги, сцены и материалы. Отдельный архив книги и ручной импорт не нужны. Можно также создать свой проект или импортировать JSON [формата WriterHelper](docs/json-import-format.md).

Нужны Windows 10/11 x64, .NET Framework 4.8 и [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/).

## Как пользоваться

- Книгу выбирайте кнопкой **«Выбрать книгу»**. Слева расположены главы, сцены и материалы книги; текст пишется в **«Рукописи»**.
- Настройте модель в **«Настройках ИИ»**: поддерживаются совместимый HTTP API и локальный исполнитель. Ключи и модель не входят в поставку.
- Выделите текст для **«Перегенерировать выделенное»** или поставьте курсор для **«Сгенерировать в этом месте»**. Результат сначала появляется отдельным кандидатом и применяется после **«Принять»**.
- В **«Предпросмотре»** доступны шрифты, масштаб и размеры полотна. Для новых книг размер по умолчанию — **A4 в книжной ориентации: 210 × 297 мм** (794 × 1123 CSS px); кнопка **A4 · книжная** возвращает этот размер. **«На всю ширину»** сохраняет книжные пропорции 210:297, меняя высоту вместе с шириной. Сохранённое оформление существующих книг сохраняется. Значения вводятся с клавиатуры, Enter или уход из поля завершает ввод. Колесо прокручивает страницы, **Ctrl + колесо** меняет масштаб, **Alt + колесо** — размеры полотна.
- **«Сохранить»** записывает материал в проект. Несохранённый ввод хранится локальным черновиком; его можно открыть по уведомлению.
- Крестик и сворачивание убирают окно в трей. Двойной щелчок по иконке возвращает окно, **«Выход»** в меню трея закрывает программу.

Данные находятся в папке `data` рядом с программой. Для обновления сохраняйте эту папку; переносите приложение целиком, вместе с DLL и служебными папками. Ключи и личные браузерные черновики в публичную поставку не включены. Актуальная авторская версия «Железного разума» из [books/iron-mind](books/iron-mind) входит в тот же архив программы. Она копируется в рабочую папку только при первом запуске новой установки. При обновлении существующая база и локальные правки не заменяются.

## Книга «Железный разум» и участие читателей

[books/iron-mind](books/iron-mind) — поддерживаемые рабочие исходники: JSON с планами, сценами и рукописями, а также каталог data с базой и историей сохранённых правок. Это самостоятельный книжный проект, который можно открыть в WriterHelper; программа подходит и для других книг.

В Windows-поставке книга открывается автоматически. JSON и рабочая база в репозитории нужны для истории изменений, форков и дополнительных способов переноса; см. [инструкцию проекта книги](books/iron-mind/README.md). Обсуждения и идеи принимаются в [Issues](https://github.com/Avalakh/WriterHelper/issues); свою версию можно вести в fork. Основную версию меняет автор. Из GitHub в авторский проект ничего не подгружается: направление обмена — только выгрузка из WriterHelper в Git.

Автор выпускает программу и книгу одной командой: `npm run release:windows -- -SourceData "ПУТЬ_К_РАБОЧЕЙ_DATA" -Publish`. Сначала сохраните правки в WriterHelper. Команда выгружает текущие материалы и историю, собирает EXE, проверяет тесты и публикует исходники и один ZIP с книгой внутри. Ключи, подключения и профиль браузера исключаются. Без `-Publish` готовится только локальная сборка.

## Контекст для генерации

**Задача** описывает, что нужно получить от ИИ. **Контекст** — материалы книги и инструкции, на которые модель должна опираться. Например, задачу «усилить напряжение, сохранив события» подкрепляют план сцены, правила мира, персонажи и стиль.

### Подготовьте материалы

1. Заполните **«Сюжет»**, план нужной главы и её сцены: события, атмосферу, участников и ограничения. Для генерации рукописи и сцен сюжет, назначенные события главы и план главы по умолчанию обязательны.
2. Укажите правила в **«Описании мира»**, манеру повествования в **«Стиле»** и сведения в **«Персонажах»**. Заполняйте текст **«Содержание»** источников: одни структурные поля не заменяют его. Подготовленные внешние материалы добавляйте как **«Источники»**. Одна ссылка без текста не загружает содержимое сайта автоматически.
3. Если факт действует только в определённой книге, локации, диапазоне глав или доступен конкретному POV, задайте соответствующие свойства правила или особенности персонажа. Они используются при отборе материалов; известное противоречие или неуточнённое состояние могут блокировать запрос.

Для рукописи и сцен стандартная схема подключает лор, мир и его правила, стиль, участников, сюжет и план главы со сценами. Соседние главы по умолчанию задают границы **названиями и номерами**, а не полным текстом предыдущей прозы. При переработке и вставке также передаётся текущий текст. Для других типов материалов схема отличается.

### Проверьте, что получит ИИ

Откройте нужный материал → **«Помощник»** → задайте **«Что создать или изменить»** → выберите модель в **«Настройках запроса»** → нажмите **«Посмотреть контекст»**.

Раскройте источники в пакете и проверьте их точный текст, применяемые промпты и оценку размера запроса. Вкладка **«Материалы»** справа — справочная панель; присутствие карточки рядом с текстом само по себе не означает, что она включена в запрос. Состав запроса проверяется через **«Посмотреть контекст»**.

### Настройте контекст через конструктор

В панели помощника откройте **«Конструктор генерации»**. Источники и промпты связаны стрелками с целью генерации.

| Роль источника | Для чего используется |
|---|---|
| Ограничение | Канон и правила, которым должен соответствовать результат |
| Основа событий | Сюжет и план того, что должно произойти |
| Стиль | Язык, ритм, POV и манера повествования |
| Участники | Сведения о персонажах |
| Граница | Соседние события, которые нельзя переносить в целевой фрагмент |
| Редактируемый текст | Исходник, который дополняется или перерабатывается |
| Промпт | Инструкция для генерации или проверки результата |

Выберите стрелку, задайте роль, включите или отключите источник. В **«Точном фрагменте»** можно указать только нужную цитату вместо целого материала; цитата должна совпадать с текстом источника. Отметка **«Обязательный»** блокирует запрос, если необходимый источник пуст. Для предыдущей прозы добавьте связь с нужной **рукописью**; для дополнительной справки используйте **«Добавить внешний текст»**.

В **«Сохранить настройку для»** выберите область действия: приложение для этого типа материала, проект, книгу, главу или конкретный материал. Нажмите **«Сохранить схему»**, вернитесь к материалу и снова проверьте контекст. Настройки наследуются; изменение общей основы может потребовать пересмотра локальных отличий.

Общие инструкции редактируются в разделе **«Промпты»**. У шаблона задаются область, тип материала, этап **«Генерация» / «Проверка»**, порядок и обязательные переменные. Для отдельной цели можно создать локальную копию.

### Если контекст не собирается

- **Пустой обязательный источник:** заполните указанный материал или осознанно измените его связь в конструкторе.
- **Не распознан диапазон событий:** в плане главы заполните **«Назначенный диапазон сюжета (если границы не распознаны)»**. Сценарный диапазон также может определяться по заголовку/строке главы или подробному плану главы.
- **Не помещается в модель:** сократите источники точными фрагментами либо выберите модель с большим контекстом и правильно задайте её лимиты. Оценка размера консервативная; приложение не обрезает материалы молча.
- **Источник или шаблон изменился:** сохраните правки, пересмотрите схему и соберите новый пакет.

Быстрые кнопки замены выделения и вставки в рукописи используют схему контекста этой рукописи. Настройте и проверьте её через помощника перед запросом. Результат остаётся кандидатом до **«Принять»**: контекст помогает модели соблюдать ограничения, но текст и факты всё равно нужно проверить.

## Запуск из исходников

Нужен Node.js 24+.

```powershell
npm ci
npm run build
npm start
```

Откройте http://localhost:4317. Сборка EXE на Windows: `npm run build:desktop` (используется C#-компилятор Windows, SDK WebView2 скачивается из официального NuGet). Проверки: `npm test`, `npm run test:startup`. Лицензии компонентов находятся в `desktop`.

При переходе с несохранёнными правками доступны «Сохранить и перейти», «Оставить черновик», «Не сохранять» и «Остаться». «Не сохранять» отменяет правки и удаляет локальный черновик только текущего материала. В предпросмотре меняется оформление; текст правится в рукописях глав. Фокус полей, прокрутка, масштаб и изменение размера окна не считаются изменениями книги.

Защита несохранённых изменений действует также в настройках ИИ, промптах и конструкторе генерации. Результаты и сценарии проверки: [аудит разделов](docs/unsaved-changes-audit.md).
